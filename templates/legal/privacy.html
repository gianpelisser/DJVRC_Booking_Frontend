POLÍTICA DE PRIVACIDADE

Última atualização: junho de 2026

1. Quem somos

O DJ VRC Booking é uma plataforma de contratação de DJs para eventos virtuais no VRChat, acessível em djvrcbooking.com. Ao usar nosso site, você concorda com esta política.

2. Dados que coletamos

Coletamos apenas os dados necessários para o funcionamento da plataforma:

  • Cadastro por e-mail: endereço de e-mail, nome de usuário e senha (armazenada em hash bcrypt)
  • Login com Discord: ID numérico, nome de usuário, nome de exibição e avatar fornecidos pela API do Discord
  • Login com Google: ID numérico, nome e foto de perfil fornecidos pela API do Google
  • Perfil DJ: nome artístico, bio, redes sociais e preferências de notificação (informados voluntariamente)
  • Bookings: dados do evento, data, horário e valor informados no pedido de contratação

3. Como usamos seus dados

  • Autenticar sua conta e manter sua sessão ativa
  • Enviar notificações sobre bookings via e-mail e/ou Discord
  • Exibir seu perfil público de DJ (apenas os dados que você escolheu compartilhar)
  • Melhorar a plataforma com base em uso agregado e anônimo

Não vendemos, alugamos nem compartilhamos seus dados pessoais com terceiros para fins comerciais.

4. Integrações externas

Usamos os seguintes serviços externos:

  • Discord OAuth 2.0 — para autenticação. Os dados recebidos são regidos pela Política de Privacidade do Discord
  • Google OAuth 2.0 — para autenticação. Os dados recebidos são regidos pela Política de Privacidade do Google
  • Discord Bot API — para envio de mensagens diretas (DMs) mediante consentimento do usuário

5. Seus direitos

Você pode a qualquer momento:

  • Editar ou excluir dados do seu perfil
  • Desvincular contas do Discord e Google
  • Desativar notificações por Discord
  • Solicitar a exclusão completa da sua conta via support@djvrcbooking.com

6. Segurança

Senhas são armazenadas com hash bcrypt. Tokens JWT com expiração são usados para autenticação. A comunicação é feita via HTTPS. Tomamos medidas razoáveis para proteger seus dados, mas nenhum sistema é 100% seguro.

7. Contato

Dúvidas sobre privacidade: support@djvrcbooking.com
